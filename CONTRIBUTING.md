# Contributing

The rules are Niko's: [arngory/niko's CONTRIBUTING.md](https://github.com/arngory/niko/blob/main/CONTRIBUTING.md)
(in Russian: [CONTRIBUTING.ru.md](https://github.com/arngory/niko/blob/main/CONTRIBUTING.ru.md)). In short:

- A short branch from `main` → a pull request → green "CI result" (`ci.yml`), "Commit messages" and "Secrets"
  (`checks.yml`) → a squash merge, its title ending in " (arngory/niko-desktop#N)". No force-push to `main`.
- Commit messages in English; no bare `#N` (write `arngory/<repository>#N` or "task N"); no `Co-Authored-By` and
  `Claude-Session` trailers. The description follows `.github/pull_request_template.md`.
- No keys, passwords, tokens or addresses of real nodes; documentation addresses in tests. "Secrets" runs gitleaks
  with `.gitleaks.toml` and `.gitleaksignore` as `main` has them.
- Everything taken from another repository is pinned to an exact version. Niko is pinned by commit in
  `.github/niko.env`, a commit of Niko's `main`, and the pin changes in a pull request of its own.

## In this repository

| What | Where |
|---|---|
| the window (Flutter) | `lib/`, `windows/`, `linux/`; tests in `test/` |
| the screens' pictures | `test/goldens/`, compared on Linux; `flutter test --update-goldens` records new ones |
| the daemon's API as Dart | `lib/gen/`, generated by `tool/gen_proto.sh` from the core's protos and Niko's `shared/proto` |
| the theme, the fonts, the icons | generated by Niko's `shared/tool/gen_tokens.py` and `gen_icons.py` (`--desktop`) |
| the daemon `nikod`, its Go, the golden fixtures | [arngory/niko](https://github.com/arngory/niko) |

A change of the daemon's API, of the tokens or of what the window reads from Niko goes to Niko first; then a pull
request here moves `.github/niko.env` to that commit with the window's side of the change.
